# Payoo Mobile Banking

A simple mobile banking web application built with HTML, Tailwind CSS, DaisyUI, and JavaScript.

### Features
- Login System
- Add Money
- Cash Out
- Transfer Money
- Get Bonus
- Pay Bill
- Transaction History

### Technologies Used
HTML5, Tailwind CSS, DaisyUI, JavaScript
